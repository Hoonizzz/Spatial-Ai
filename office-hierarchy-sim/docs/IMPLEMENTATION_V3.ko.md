# Office Hierarchy v3 구현 기준

## 직급별 인원수

- 사장·팀장·대리·신입 인원수를 각각 입력하고 설정을 적용한다.
- 기본은 1 / 3 / 6 / 12명이다. 직급별 0~40명, 전체 최대 120명으로 제한한다.
- 사장이 여러 명일 때도 동일 직급끼리는 위계 반응을 만들지 않는다. 하급자는 현재 감지한 상급자 중 직급이 높은 사람, 같은 직급이면 가까운 사람을 우선한다.
- 사장이 없을 때 사장 거리 지표는 미정(`null`, 화면에서는 `—`)으로 표시한다. 여러 사장이 있으면 가장 가까운 사장까지의 거리이다.
- 모든 직급을 0명으로 설정하면 빈 사무실을 표시한다. 인물 선택을 비활성화하고 재설정·카메라·실험 기능은 계속 사용할 수 있다.
- 현재 인원수는 범례, 선택 목록, 3D 인물, 전체 시야 수, 통계, JSON 및 실험 CSV에 함께 반영한다. 인원수를 줄이면 기존 인물과 시야 그래픽을 제거한다.
- 같은 seed와 같은 인원수·설정은 같은 배치와 결과를 재현한다. 초기 방 분포는 기존 직급별 배치 패턴을 반복해 확장한다. 공유 책상 수는 22개로 유지한다.

## 기본 시야

| 직급 | 시야각 | 기본 주의 반경 |
|---|---:|---:|
| 사장 | 110° | 3m |
| 팀장 | 110° | 2.5m |
| 대리 | 110° | 3.5m |
| 신입 | 110° | 4.5m |

사장 이외 직급의 기존 반경을 절반으로 줄인 기본값이다. 벽 차폐와 감지 시작 0.15초·해제 유예 0.7초는 유지한다. Equal vision·Strong hierarchy 실험 프리셋은 비교를 위한 별도 반경을 명시적으로 적용한다.

## 상급자 감지와 방향 전환

- 새 상급자 감지를 현재 상태의 조기 종료 조건보다 먼저 처리한다. 기존 추적·회피 경로 때문에 새 사장 감지를 무시하지 않는다.
- 더 높은 직급의 새 위협은 즉시 우선 처리한다. 같은 직급 사이의 목표 변경에는 최소 0.5초 간격을 적용한다.
- 업무 위장과 도주 경로 모두 첫 이동 방향이 상급자 쪽을 향하면, 벽과 다른 사람을 피할 수 있는 후퇴·우회 지점을 찾아 경로 앞에 추가한다.
- 업무 앵커는 현재 위치에서 1m 이상 떨어지고 위협에서 1.2m 이상 떨어진 후보를 사용한다. 적절한 경로가 없으면 도주로 전환한다.
- 같은 감지 에피소드 안에서 일시적으로 순찰·폰 행동으로 돌아와도 이전 반응 선택을 재사용한다. 매 프레임 확률을 다시 추첨하지 않는다.
- 실제 이동이 막혀도 의도한 회피 방향으로 몸과 시선을 회전한다. 회전 속도는 최대 12 rad/s이며, 벽이나 다른 사람을 관통해 위치를 바꾸지 않는다.
- 가려진 목표가 단지 시야 부채꼴의 기하학적 내부에 있다는 이유만으로 감지되지는 않는다. 실제 차폐 판정과 짧은 감지 지속 조건을 통과해야 반응한다.

## 경로 중첩과 회피

- 주변 사람의 실제 속도와 이동 의도를 이용해 최대 1.25초 앞의 상대 위치를 예측한다.
- 속도 유지·감속·정지, 좌우 우회·후퇴 후보를 비교한다. 정면 교행에서는 자신의 진행 방향 오른쪽을 우선 고려한다.
- 교차 상황에는 직급과 무관한 결정적 ID 우선순위를 사용해 한쪽이 양보하도록 한다. 같은 seed로 재현할 수 있다.
- 최종 이동에는 기존 swept collision 검사를 유지해 신체 중심 간 최소 0.60m를 지킨다.
- 정체가 이어지면 주변 사람을 임시 장애물로 고려한 A* 경로를 찾거나, 비켜 설 수 있는 지점을 찾아 이동한다. 경로 평활화 단계에서도 사람을 가로질러 자르지 않는다.
- 가까운 경유점도 다음 구간이 가구·벽에 막히면 유지한다. 모서리를 돌아 나오는 데 필요한 짧은 경유점을 거리 허용오차만으로 삭제하지 않는다.
- 좁은 통로·혼잡에서는 감속이나 대기가 발생할 수 있다. 다른 사람과 벽을 무시하는 순간이동은 사용하지 않는다.

## 화질

- 기본 `High`는 최소 2배 해상도 렌더링과 최대 4096² 그림자를 사용한다.
- `Ultra`는 최대 3배 해상도, `Balanced`는 기기 기본 해상도와 2048² 그림자를 사용한다. GPU의 최대 텍스처·렌더 버퍼 크기에 맞춰 제한한다.
- 윤곽선 안티앨리어싱을 유지하고, 텍스트 라벨 해상도를 높이며, 톤 매핑·조명을 조정한다. 블록형 얼굴의 픽셀 스타일은 유지한다.
- 화질 선택은 시뮬레이션 시간·seed·경로를 초기화하지 않는다. 정지한 장면은 카메라나 설정이 변할 때만 다시 그려 불필요한 렌더링을 줄인다.
