# Office Hierarchy v2 구현 변경점

원본 `SIMULATION_SPEC.md`는 초기 명세로 보존한다. 아래 내용은 사용자가 추가 요청한 다섯 가지 변경을 반영한 현재 구현 기준이다.

## 1. 모든 에이전트의 시야 표시

- 22명 전원의 시야 부채꼴을 기본 표시한다. `All FOV`를 끄면 선택한 한 명의 시야만 확인할 수 있다.
- 기본 시야각 110°, 직급별 주의 반경 3 / 5 / 7 / 9m는 유지한다.
- 3D와 2D가 같은 시야 투영 함수를 사용한다. 벽·가구·공간 외곽에 가려지는 부분을 잘라 표시한다.
- 선택한 사람은 시야 윤곽과 바닥 링으로 강조한다. 인물 클릭 또는 ID 선택으로 변경한다.

## 2. 사무실 면적 2배

- 기존 22 × 14m = 308㎡에서 약 31.1 × 19.8m = **616㎡**로 확대한다.
- 가로·세로를 각각 √2배로 늘리는 **면적 기준 2배**이다.
- 방 경계, 문 위치·폭, 가구 중심 좌표를 확대한다. 책상·가구 자체의 크기, 사람의 반경, 보행 속도, 시야 반경은 유지한다.
- 경로 탐색, 벽 충돌, 방 판정, 초기 배치, 체류시간 및 히트맵도 확대된 실제 좌표를 사용한다.

## 3. 화장실·회의실·라운지 회피

- 상급자 발견 시 기본 반응은 업무 위장 45%, 회피 55%를 유지한다.
- **회피 선택 중** 화장실 비중을 기본 25%로 설정한다. 나머지는 회의실 또는 라운지로 이동한다. UI에서 0~100% 조절할 수 있는 모델링 가정이다.
- 회의실과 라운지에서 각각 8개 후보를 검사한다. 실제 A* 도달 가능 여부와 이동 거리, 상급자와의 거리, 시선 차폐, 주변 인원 및 이미 선택된 목적지를 평가한다.
- 상태는 `FLEE_TO_ROOM` → `ROOM_HIDE`이다. 도착 후 기본 4~8초 머무른다. 상급자가 다시 감지되면 최소 회피 시간 이후 다른 방으로 이동한다.
- 화장실 예약을 포함한 정원 4명 제한은 유지한다. 만실·예약 만료·경로 실패 시 회의실이나 라운지로 전환한다.
- 두 방에 도달할 수 없을 때만 업무공간 내 회피를 최후 대안으로 사용한다. 회의실과 라운지에는 별도의 인원 제한을 가정하지 않는다.
- 통계는 화장실 회피, 방 회피, 업무공간 최후 회피를 각각 기록한다. 방 회피 횟수에는 노출된 은신처에서 재이동한 경우도 포함한다.

## 4. 블록형 3D 인물

- Three.js 기반의 기본 3D 화면과 회전·확대·이동 카메라를 제공한다. 필요하면 2D 평면 화면으로 전환할 수 있다.
- 사각형 머리·몸·팔·다리, 픽셀 얼굴과 머리카락을 조합한 인물을 로컬에서 생성한다. Minecraft의 원본 모델이나 텍스처 파일은 사용하지 않는다.
- 셔츠 색은 직급을 구분하고, 피부·머리카락·바지에는 여러 변형을 사용한다. 직급에 따른 신체 크기 차이는 없다.
- 보행 모션은 실제 이동 거리에 연동한다. 핸드폰·업무 위장에는 팔 동작을 적용한다. 일시정지하면 동작도 정지한다.
- 3D는 2D 경로·충돌·시야 모델의 시각화이며, 층간 이동이나 점프 물리는 추가하지 않는다.
- WebGL을 사용할 수 없는 환경은 이유를 표시하고 2D 평면 화면으로 전환한다.

## 5. 랜덤 리셋과 재현

- `Random reset`은 브라우저의 암호학적 난수로 새 uint32 seed를 만들고, 안전 거리 조건을 만족하는 배치로 초기화한다.
- seed 입력란도 실제 적용한 값으로 갱신한다.
- `Replay seed`는 입력한 seed로 동일한 초기 배치를 다시 생성한다.
- 설정 적용과 실험 시나리오 비교는 기존처럼 seed를 고정해 재현성을 유지한다. 랜덤 리셋은 실행 중/일시정지 여부와 카메라 방향을 유지한다.

## 배포 및 검증

- `npm run build`는 정적 파일과 저장소 루트의 메인 페이지를 함께 갱신한다.
- 기능 검증에는 면적·물리 크기, 모든 직급의 시야, 방 회피·재이동, 랜덤 seed·재현, 30분 가상 실행의 충돌·정원·정체 검사를 포함한다.
- 브라우저 검증은 3D 인물·시야 수, 인물 선택, 카메라 조작, 2D 전환, 설정·통계·내보내기, 시나리오 비교 및 모바일을 확인한다.
